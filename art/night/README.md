# Dead of Night — the art

Everything under `public/assets/night/` is generated by the scripts in this
folder, in Blender 5.1, headless. Nothing is downloaded: every mesh, texture,
sign, sky and animation is made here from code, on top of High Noon's
libraries (`art/western/dustcreek` for the town pipeline,
`art/western/characters/charlib` for people), which are imported read-only
(added to `sys.path`, never edited).

| file | what | budget | built by |
|---|---|---|---|
| `road.glb` + `road_albedo_*.webp`, `road_flicker_*.webp` | Route 9, Miller's Gas & Eats, the motel, the fields, the contract nodes; the layers the flashlight and the lamp's flicker read | ≤ 14 MB together | `build_road.py` |
| `sky.webp` | the night sky, equirectangular | — | `build_road.py sky` |
| `poster.webp` | the arcade card / share image | — | `build_road.py poster` |
| `walker.glb` | the dead: one body, six outfits, four hair, runner, bloater, crawler | 10–18k tris dressed | `characters/build.py` |
| `mechanic.glb` | the Mechanic (boss): mask, tyre iron | 10–18k | `characters/build.py` |
| `survivor.glb` | the daughter and the owner, a lantern | 10–18k each | `characters/build.py` |
| `cat.glb` | the black cat | small | `characters/build.py` |

## Building

All commands from the repository root. `-t 4` keeps Blender to four threads
(other jobs share the machine); Cycles renders and bakes on the GPU (Metal).

```sh
B=/Applications/Blender.app/Contents/MacOS/Blender

# the road: scene -> sky -> bake -> export -> review -> poster
$B -b --factory-startup -t 4 -P art/night/build_road.py                 # full quality
$B -b --factory-startup -t 4 -P art/night/build_road.py -- --quick      # fast iteration
$B -b --factory-startup -t 4 -P art/night/build_road.py -- bake export  # rerun stages alone

# the characters (each also saved as art/night/build/characters/<who>.blend)
$B -b --factory-startup -t 4 -P art/night/characters/build.py
$B -b --factory-startup -t 4 -P art/night/characters/build.py -- --only walker --quick

# the character review set (turnarounds, faces, hands, clip sheets, 10/25/40 m shots, lineup)
$B -b --factory-startup -t 4 art/night/build/characters/walker.blend -P art/night/characters/review.py \
   [-- --what turn,faces,strips,distance,lineup --clips claw,lunge --quick]
# a single head, fast: sculpt, game mesh, bake, close renders (walker|runner|bloater|crawler)
$B -b --factory-startup -t 4 -P art/night/characters/headtest.py -- walker

# the road seen as the game shows it: road.glb imported back (lit, fog, beam),
# and the built dead standing on it at 10, 25 and 40 m in the flashlight
$B -b --factory-startup -t 4 -P art/night/build_road.py -- glbreview castreview

# a character file again from its saved scene (new names, new clips), in seconds
$B -b --factory-startup -t 4 art/night/build/characters/walker.blend -P art/night/characters/reexport.py

# prove the contract (plain Python + PIL, no Blender): nodes, extras, the play
# view at 16:9 / 4:3 / 1.2:1, the cat's perches, every WebP's alpha, budgets
python3 art/night/check_night.py
node art/night/tools/draco_check.cjs public/assets/night/road.glb
```

Run times on this Mac (M-series, sharing it with two other bakes):
see [Timings](#timings).

Review renders go to `art/night/build/review/` (git-ignored, like the .blend
files and the intermediate bakes in `art/night/build/`).

## Decisions the contract left open

These match what the game reads (`src/games/night/world/road.ts`,
`stage.ts`, `shading.ts`, `rigs.ts`, `assets.ts`). The few places where
the art and the game's code still differ are listed at the end, under
[For the game to adapt](#for-the-game-to-adapt).

### The two layers of a baked group: how `lit` and `albedo` travel

Every baked group of `road.glb` (`ground`, `near`, `station`, `west`, `east`,
`far`, `trees`) is split by surface into meshes whose materials are
`night.<group>.<surface>`. Each is **unlit** (`KHR_materials_unlit`) and
three.js loads it as a `MeshBasicMaterial` whose `map` is the layer the game
shows. Its extras name the other layers, WebP files beside `road.glb`:

| where | layer | notes |
|---|---|---|
| `baseColorTexture` (the `map`) | **lit** | moon, sky, the steady practical lights (neon, the motel's candles, the booth, the pilot lamp) and the streetlight, AO, the wet asphalt's glossy reflections seen from the player's eye. sRGB, **display-referred** (graded through AgX, Medium High Contrast, and the night grade): show it as is, no tone mapping, no lights. |
| `extras.albedo` → `road_albedo_<group>.webp` | **albedo** | the surface's own colour, sRGB, same UVs and size as `lit`, for the flashlight and the muzzle flash. |
| `extras.flicker` → `road_flicker_<group>.webp` | **street** | where the streetlight's light falls, greyscale (read `.r`, linear), half size. Only for the groups the lamp reaches (all but `trees`). |
| `extras.surface` | | `asphalt`, `dirt`, `wood`, `metal`, `glass`, `cloth`, `plant`, `sandbag`, `water` (also on every mesh node). |
| `extras.glow` | | 1 everywhere: `lit` already carries every lamp, neon letter and candle at its baked brightness. |

The game's shader (`shading.ts`, `BAKED_FRAGMENT`):

```
colour = max(lit * glow - albedo * uStreetTint * street * (1 - on), 0) + albedo * (beam + flash) / pi
```

`street` is in units of `albedo × SODIUM` with the game's
`SODIUM = (1, 0.56, 0.23)`, divided by the scene's **`extras.flicker_scale`
(8.25)** so it fits 8 bits: `uStreetTint` must be `SODIUM × flicker_scale`
for the lamp to go fully out (see below).

How the flicker map is made: the lit bake is rendered twice for the groups
the streetlight reaches (with the lamp and without), the fraction of `lit`
the lamp adds is kept, and at export it is turned into the game's units:
`street = lum(dec(lit) − dec(lit without lamp)) / lum(dec(albedo) × SODIUM)`
(`dec` = sRGB to linear, as the GPU samples them). `glb_street_off.png` in
the review set is road.glb rendered by that formula with the lamp dead.

Fog is **not** baked (`extras.fog_baked = false`): the game draws it. The
scene's extras hold the fog the review renders use: `fog_color` (`#2d3744`,
the sky's own horizon measured from `sky.webp`, so the far road melts into
the sky; the game reads it), `fog_density` (FogExp2 on view depth, 0.0182:
60% visibility at 40 m, 30% at 60 m, gone by ~110 m) and `fog_ground` (a
ground-hugging layer: extinction 0.012/m, 2.2 m scale height). The sky must
not take the fog: the moon painted in `sky.webp` is shot through
`moon.disc`, the **hit target** — a disc 380 m out exactly over the painted
moon, 15% larger than it (`extras`: `radius_m`, `distance_m`).

Every texture, in the GLBs and beside them, is RGB (no alpha channel): a
WebP encoder throws away the colour under zero alpha unless told `exact`, so
nothing here stores data under alpha. `check_night.py` proves it for every
image.

### The corn

The corn is its own mesh, `corn` (children `corn.1..3`), vertex-coloured
instead of textured so the game can sway it. Its material `night.corn` is
unlit with `extras.bake = "vertex"` (what `stage.ts` looks for). `COLOR_0`
is `lit` (linearised display values; three.js reads vertex colours as
linear), `_ALBEDO` (linear), `_FLICKER` (the lamp's light, the same units as
the flicker maps, ÷ `flicker_scale`) and `_SWAY` (0 at the ground .. 1 at
the tassel). glTF requires custom attribute names to start with `_`, so
three.js names them `_albedo`, `_flicker`, `_sway` (see below). Blender's own
glTF importer chokes on several custom Draco attributes; three.js decodes
them: `tools/draco_check.cjs`.

### Nodes added or interpreted

- **Everything the play view frames fits it** at 16:9, 4:3 and the stage's
  narrowest, 1.2:1 — the barricade places, every lane's waypoints from the
  second on within 60 m, the spawns' paths, the survivors' runs, the
  secrets, the cat's perches, the whole moon — at the widest framing the
  game allows (`checkFraming`, 28.9° either side). `check_night.py`
  recomputes the game's `playSights` from road.glb and proves it; the
  tightest framings come out at a vertical 40° (16:9), 42° (4:3), 46°
  (1.2:1). One exception, the radio (below).
- `barricade.1-5`: five places across the middle of the barricade, 0.75 m
  apart, 4 m out (a figure's shoulders at 26° at the ends). `extras.vp`,
  `clip: claw`.
- `lane.<id>.<n>` carry `spread` (road 1.5, corn 0.8, trees 1.1) and
  `width_m`. The tree line now comes out of the pines east of the motel and
  walks along its front, off the right of the screen, before it crosses
  the lot into view (its old waypoints in the lot were 27–38° right).
- `spawn.bus` is the **foot of the bus's door** and `spawn.fence` the
  **rail**, both with `spread` 0.3 and the clip in `extras.clip`. The game
  carries the dead along the first stretch of the spawn's path while the
  clip plays: that stretch is 0.5 m (bus) and 0.9 m (fence), and the clips
  carry the rest — `climb_out` starts 0.55 m back and 0.42 m up in the
  doorway, `vault` 1.1 m back in the field — so the body steps down from the
  door, or goes over the rail at the clip's middle, and lands on the path.
  `spawn.booth` (behind the phone booth, `walk`). `spawn.fence` is 16 m out:
  the overturned pickup hides the fence nearer.
- `path.survivor.1-2.<k>`: out of the corn (at the crossroads, and through
  the fence's gap), across the road to the motel office's door, where the
  owner's phone is. In view all the way.
- `street.lamp`: the streetlight's lens, its own mesh (the game dims it as
  the lamp stutters). `light.street` is the lamp head; `light.neon` the
  pole sign's tube; `light.motel.<n>` the rooms with candles; `light.booth`
  (added) the phone booth's panel.
- `moon` (empty, −Z = moonlight; `extras` direction, colour, strength for
  lighting the characters) and `moon.disc` (the target, azimuth −24°, 14° up
  — low over the fields to the front-left, in the play view; the contract
  left the moon's place open). The moon backlights the road: the dead come
  at you rim-lit, faces in shadow until the beam finds them.
- `secret.cat.spot.1-4`: a **fence post** by the corn (where the cat is
  first seen), the top of the **Gas & Eats sign**, the **wrecked car's
  roof**, the **motel sign**. Each is found on the real geometry (a flat
  top, seen from the eye), in the play view, more than 1.2 m from every
  other secret. `extras.on` names it. (Not the pickup's cab: the pickup lies
  42° left of the view's centre.)
- `calib.1-9` carry `extras.kind` (hanging, fence_post, bus_window_sill,
  booth_roof, …) and, for the hanging jars, `extras.hook`.
- `secret.radio` sits on a shelf behind the diner's window, at the right
  edge (32.6° right): on screen from about 1.5:1 (16:10, 16:9, wider), off
  screen at 4:3 and 1.2:1 — every nearer place inside the diner is hidden
  from the eye by the pump. See below.
- `secret.phone.motel` is an empty at the office's payphone.
  `secret.drivein.lamp` is on the projector booth's side facing the road.
  `secret.drivein.screen` is a plane with 0..1 UVs, for a video texture.
  `secret.scarecrow` has its origin at its base; `secret.scarecrow.head` is a
  child pivoting at the neck.
- The contract's empties are re-placed at every export (`contract.refresh`),
  from the baked scene: moving a node never needs a new bake.

### Characters

- **One armature**, High Noon's bone names, +Z forward in glTF, feet at the
  origin, clips at 30 fps. The walks are in place; the clip meta gives the
  ground speed each was made for. `climb_out` and `vault` carry their own
  root motion (above).
- **walker.glb has a 2048² atlas** (not 1024²): it holds thirteen people's
  worth of skin and cloth (the base, six outfits, four hair, the runner, the
  bloater, the crawler). The eyes have their own 128² texture.
- **Dressing** (`extras.dressing` on the scene): a walker is `char.walker` +
  one `var.outfit.*` + one `var.hair.*` (or none; with the trucker's and
  hunter's caps use `short` or none) + `eyes`. **`char.runner`,
  `char.bloater` and `char.crawler` are whole people** in their own clothes
  and hair: show one of them + `eyes`, nothing else (see below).
- The crawler's own clips: `crawl`, `idle.low` (waiting on its belly, head
  up), `claw.low` (rearing on one arm and raking at the bags, strikes at
  0.45 s and 1.0 s), `hit_head.low`, `death.low` (flat on its face, the thud
  at 0.5 s) — the names in `rigs.ts`'s `CLIP_FALLBACKS`.
- The bloater's belly is part of `char.bloater` (no separate `belly` node);
  `bloat_burst` doubles it over at 1.32 s (`extras.clips.bloat_burst.burst_s`),
  where the game's cloud covers it.
- **Eyeshine**: `eyes` is a separate mesh with material `eyes` whose
  `emissiveTexture` is the shine (a sickly green-gold over the iris, half over
  the white), `emissiveFactor` 1. The game drives `emissiveIntensity`:
  **0 in the dark**, up to **~3** in the beam's centre (`extras.eyeshine`).
  The eyes are rigid on `head`, their two halves either side of the head's
  middle (what `rigs.ts`'s `eyeFrame` measures). The cat's are green, the
  same scheme. Beyond ~15 m an eye is smaller than a pixel: the game's own
  eyeshine glow carries the tell there.
- **Clip meta** (`extras.clips` on the scene): per clip, `loop`, `speed_mps`
  (shamble 0.85, limp 0.7, drag 0.6, lurch 1.1, run 3.5, crawl 0.5; the
  survivors' run 5.0, run_lantern 4.4; the cat's walk 0.6), and moments:
  `claw.strike_s`, `lunge.strike_s`, `stagger.root_back_m`, the deaths'
  `thud_s`, `bloat_burst.burst_s`, `swing.impact_s`, `mask_off.mask_free_s`.
- The dead walk **face first**: in the idle and the walks the neck juts
  forward and the head tips back on it, so the face and the eyes come up
  toward a player at 1.7 m.
- The survivors are living: their eyes are baked into `var.person.*`'s own
  atlas and do not shine. `prop.lantern` hangs under `socket.lantern` (on
  `hand.L`), with `lantern.flame` its child: its own emissive material
  `flame` the game flickers.
- **The Mechanic** is 1.15× a walker: the scale is on the armature object,
  so clips shared with the walker play as is. `var.mask` is rigid on `head`
  and a separate mesh (hide it and throw a loose copy when it flies off);
  `prop.tyre_iron` is under `socket.weapon` (on `hand.R`).

### For the game to adapt

Where the art cannot follow the game's current code, or should not:

1. **`uStreetTint = SODIUM × flicker_scale`** (road.glb's scene extras,
   8.25): the flicker maps are divided by it to fit 8 bits. With the tint at
   `SODIUM × 1` the lamp only dims to about 1/8 of its pool.
2. **The corn's attributes** arrive as `_albedo` and `_flicker` (glTF's rule
   for custom names): `geometry.setAttribute("albedo", …_albedo)` and
   `("street", …_flicker)` before `bakedMaterial` sees them.
3. **`dressDead`**: `char.runner`, `char.bloater` and `char.crawler` are
   whole people. Give them no `var.hair.*` and no `var.outfit.*` (today a
   runner gets an outfit and all three may get a hair piece).
4. **`CLIP_SPEED`** should match the clips (or read `extras.clips`):
   shamble 0.85 (not 1.0), limp 0.7 (0.85), drag 0.6 (0.75), crawl 0.5
   (0.45), run_lantern 4.4 (4.2).
5. **The radio** is a wide-screen secret (32.6° right, behind the diner's
   window as the design has it "at the right edge"): leave it out of the
   play framing's sights below ~1.5:1, or the framing falls back to the
   widest and the radio is still off screen. Bringing it into a 4:3 view
   would mean moving the diner north and baking again.
6. **The cat** is first seen on a fence post, then the Gas & Eats sign, the
   wrecked car, the motel sign (the design's pickup cab, canopy and phone
   booth are out of the play view or too close to other secrets); the
   design doc's secret text is updated to match.
7. There is no `belly` node on the bloater (above).

## How it is made

(see the module docstrings; the short of it)

- `roadlib/layout.py` — every position on the road in one place.
- `roadlib/ground.py` — one height field and one big procedural shader for
  asphalt, paint, concrete, gravel, soil, grass, puddles and wetness.
- `roadlib/station.py`, `motel.py`, `roadside.py`, `farm.py`, `far.py`,
  `trees.py`, `corn.py` — the builders.
- `roadlib/contract.py` — the contract's nodes, placed by ray casts against
  the finished scene, and the sightline report.
- `roadlib/bake.py` — per-group atlases, the lit/albedo/flicker passes.
- `roadlib/export.py` — materials for glTF, Draco + WebP.
- `roadlib/post.py` — fog applied to review renders in linear light, the
  display transform.
- `characters/deadlib/` — the dead: heads (`heads.py`: High Noon's head
  sculpt pushed toward the grave, with open sockets for separate eyes),
  eyes, hands, hair grown from the head mesh, outfits, the runner / bloater /
  crawler, the Mechanic, the survivors, the cat (its own rig), the clips.

### A note on the western library

`dustcreek.post.read_exr_layers` reads subimage 0 for every layer (the
position pass came back as the colour). `roadlib/post.py` has its own reader
that reads each subimage by index. The western file is untouched.

## Texture memory

`road.glb` and its layers are 6.3 MB on disk, but its atlases unpack to about 0.5 GB of
RGBA8 with mipmaps (the 4096² near group and the 4096×2048 ground are 0.26 GB
of that). On a low tier the game can halve the atlases at load (draw them into
a half-size canvas) — the night hides it well beyond the barricade.
